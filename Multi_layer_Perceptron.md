## Часть 1. Зачем менять функцию активации

В персептроне используется **функция Хевисайда** (ступенька):

$$ f(z) = \begin{cases} 1, & z \geq 0 \ 0, & z < 0 \end{cases} $$

Здесь $z$ — взвешенная сумма входов персептрона: $z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$ (полный разбор этой записи — в части 2). Функция $f$ превращает это число в $0$ или $1$.

Такая функция хорошо подходит для одного нейрона, обучаемого простым правилом коррекции ошибки. Но у неё есть фундаментальная проблема, которая проявляется при объединении нейронов в несколько слоёв: её производная равна нулю почти везде, а в самой точке разрыва вообще не определена. Производная показывает, насколько сильно меняется выход функции при малом изменении её аргумента. Если производная равна нулю, малые изменения весов никак не отражаются на выходе — сигнал об ошибке не может "пройти" через такую функцию назад к весам.

Метод обучения многослойных сетей, называемый **обратным распространением ошибки** (рассматривается в одной из следующих лекций), опирается именно на производную функции активации, чтобы определить направление и величину изменения каждого веса. Без ненулевой производной такое обучение невозможно в принципе — это и есть главная причина, по которой в нейронных сетях используются другие функции активации, а не ступенька.

Требования к "хорошей" функции активации:

1. гладкость — без разрывов;
2. дифференцируемость почти на всей области определения;
3. нелинейность — она не должна сводиться к прямой линии (почему это важно — отдельная тема в части 6).

Далее разбираются три функции активации, ставшие основными в истории развития нейронных сетей: **сигмоида**, **гиперболический тангенс** и **ReLU**, а также кратко — их более современные варианты.

|$\sigma(z)$|сигмоида|Строчная греческая буква "сигма" — стандартное обозначение сигмоидальной функции (не путать с оператором суммы $\Sigma$ — это разные символы и разные роли)|

|$e^{-z}$|экспонента с отрицательным показателем|Убывает к нулю при росте $z$; растёт к бесконечности при убывании $z$|
|$\tanh(z)$|гиперболический тангенс|Читается "тангенс гиперболический от зет"|
|$\max(a, b)$|максимум|Оператор, возвращающий большее из двух чисел|

|$\frac{d}{dz}$|оператор дифференцирования|Альтернативная запись производной, равнозначная $f'(z)$|

## Часть 3. Сигмоида (Sigmoid)

### 3.1 Формула

$$ \sigma(z) = \frac{1}{1 + e^{-z}} $$

### 3.2 Описание поведения

Функция принимает любое действительное число $z$ (от $-\infty$ до $+\infty$) и сжимает его в открытый интервал $(0, 1)$: значение никогда не достигает точно $0$ или точно $1$, только приближается к этим границам. При больших положительных $z$ результат приближается к $1$, при больших по модулю отрицательных — к $0$, а при $z=0$ функция принимает значение ровно посередине, $0.5$.

Такая форма исторически сделала сигмоиду удобной для интерпретации выхода нейрона как **вероятности** — например, "вероятность того, что объект принадлежит положительному классу".

### 3.3 Производная

$$ \sigma'(z) = \sigma(z)\cdot(1 - \sigma(z)) $$

Особенность формулы: производную можно выразить через значение самой функции, не пересчитывая заново экспоненту — это удобно как для ручных выкладок, так и для программной реализации.

Максимум производной сигмоиды достигается ровно в точке $z=0$ и равен $0.25$. При удалении от нуля в любую сторону производная убывает к нулю.

### 3.4 Проблема затухающего градиента

Поскольку максимум производной сигмоиды невелик, а при больших по модулю $z$ производная стремится к нулю, нейрон, чей вход регулярно оказывается далеко от нуля, почти не получает сигнала для обновления весов. Такое состояние называется **насыщением (saturation)** — функция "выходит на плато" и перестаёт реагировать на изменения входа. В сети из многих слоёв такие маленькие значения производной перемножаются друг с другом при передаче сигнала об ошибке от выходного слоя к входному, и итоговое значение становится исчезающе малым. Это явление называется **затуханием градиента** (_vanishing gradient_) и было одной из главных причин, тормозивших обучение глубоких сетей до начала 2010-х годов.

## Часть 4. Гиперболический тангенс (Tanh)

### 4.1 Формула

$$ \tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}} $$

### 4.2 Описание поведения

Функция похожа на сигмоиду по форме S-образной кривой, но её область значений — интервал $(-1, 1)$, и она симметрична относительно нуля: $\tanh(-z) = -\tanh(z)$. При $z=0$ функция принимает значение ровно $0$.

### 4.3 Производная

$$ \tanh'(z) = 1 - \tanh^2(z) $$

Максимум производной достигается при $z=0$ и равен $1$ — вдвое больше, чем у сигмоиды.

### 4.4 Смысл центрирования вокруг нуля

Поскольку выход tanh может быть как положительным, так и отрицательным (в отличие от сигмоиды, чей выход всегда положителен), среднее значение выходов слоя из нескольких нейронов с tanh оказывается ближе к нулю. Это устраняет систематическое смещение, накапливающееся при переходе сигнала от слоя к слою, и на практике ускоряет обучение по сравнению с сигмоидой. Проблема затухающего градиента при этом сохраняется, но в менее выраженной форме — за счёт большего максимума производной.

## Часть 5. ReLU (Rectified Linear Unit)

### 5.1 Формула

$$ \text{ReLU}(z) = \max(0, z) $$

Эквивалентная кусочная запись:

$$ \text{ReLU}(z) = \begin{cases} z, & z \geq 0 \ 0, & z < 0 \end{cases} $$

### 5.2 Описание поведения

Положительные значения $z$ проходят через функцию без изменений, отрицательные — обнуляются. В отличие от сигмоиды и tanh, у ReLU нет верхней границы: при сколь угодно большом положительном $z$ результат продолжает расти линейно.

### 5.3 Производная

$$ \text{ReLU}'(z) = \begin{cases} 1, & z > 0 \ 0, & z < 0 \end{cases} $$

В точке $z=0$ производная формально не определена (график имеет излом), но на практике ей присваивают значение $0$ или $1$ — на результат обучения сети это почти не влияет.

### 5.4 Почему ReLU стал стандартом

Производная ReLU на положительной полуоси не убывает и не зависит от величины $z$ — она всегда равна $1$. Это устраняет затухание градиента для активных нейронов и остаётся неизменной вне зависимости от того, сколько слоёв стоит подряд. Помимо этого, вычисление ReLU требует лишь сравнения с нулём — никаких экспонент, в отличие от сигмоиды и tanh, что делает её на порядки быстрее при больших сетях. Именно широкое внедрение ReLU (в частности, в архитектуре AlexNet в 2012 году) стало одним из факторов, сделавших возможным эффективное обучение действительно глубоких сетей — десятков и сотен слоёв.

### 5.5 Проблема "мёртвых нейронов" (Dying ReLU)

Если веса и смещение нейрона настроились так, что его $z$ оказывается отрицательным на всех примерах обучающей выборки, производная такого нейрона всегда равна нулю. При нулевой производной веса перестают изменяться, и нейрон навсегда "застревает" в состоянии, где выдаёт ноль, независимо от входа. Такой нейрон принято называть "мёртвым" — формально он остаётся частью сети, но фактически не участвует в вычислениях.

## Часть 6. Более современные варианты (обзорно)

Три разобранные функции — исторически основные, но не единственные. В современных архитектурах используются и другие варианты, каждый из которых решает конкретный недостаток предшественников:

- **Leaky ReLU** — вместо полного обнуления отрицательной части пропускает небольшую её долю (например, $0.01z$). Это решает проблему "мёртвых нейронов", поскольку производная никогда не становится ровно нулём.
- **Parametric ReLU (PReLU)** — тот же принцип, что у Leaky ReLU, но коэффициент наклона отрицательной части не фиксирован заранее, а подбирается в процессе обучения вместе с остальными весами.
- **ELU (Exponential Linear Unit)** — на отрицательной части использует не прямую линию, а плавную экспоненциальную кривую, что делает переход через ноль более гладким и, по ряду исследований, ускоряет обучение.
- **GELU и Swish** — более гладкие, "мягкие" версии ReLU, применяемые в современных архитектурах трансформеров (включая большие языковые модели). Их формулы сложнее, но идея та же: сохранить преимущества ReLU, избавившись от резкого излома в нуле.
- **Softmax** — принципиально другая по назначению функция: применяется не поэлементно, а сразу ко всему вектору выходов последнего слоя, превращая набор чисел в распределение вероятностей по нескольким классам (сумма всех выходов равна единице). Используется в задачах многоклассовой классификации — это будет отдельно разобрано при переходе к задачам классификации на несколько категорий.

## Часть 7. Почему функция активации обязана быть нелинейной

Если в качестве функции активации использовать просто саму взвешенную сумму без какого-либо преобразования (то есть $f(z) = z$), то результат работы любого количества слоёв, поставленных подряд, математически эквивалентен работе одного-единственного слоя. Композиция нескольких линейных преобразований — снова линейное преобразование, с другими, но всё равно линейными, параметрами.

Отсюда следует, что без нелинейной функции активации глубина сети (число слоёв) не даёт никакого выигрыша в выразительной силе — сеть из ста линейных слоёв способна выучить ровно то же самое, что и один линейный персептрон, то есть снова только линейно разделимые задачи. Нелинейность, вносимая функцией активации между слоями, — именно то, что позволяет сети строить сложные, изогнутые границы решений и решать задачи вроде XOR, разобранные ранее.

Это напрямую связано с **теоремой об универсальной аппроксимации** (_Universal Approximation Theorem_): она утверждает, что сеть с одним достаточно широким скрытым слоем и подходящей нелинейной функцией активации способна приблизить практически любую непрерывную функцию с любой заданной точностью. Теорема не говорит, как именно найти нужные веса (это отдельная задача обучения), но гарантирует, что сама архитектура принципиально обладает нужной выразительной силой — при условии, что активация нелинейна.

## Часть 8. Насыщение и выбор функции на практике

Понятие **насыщения**, упомянутое применительно к сигмоиде, — общий термин для любой ситуации, когда функция активации выходит на пологий участок (плато) и её производная становится близкой к нулю. Сигмоида и tanh насыщаются с двух сторон (и при больших положительных, и при больших отрицательных $z$), ReLU — только с одной (при отрицательных $z$), а её современные варианты (Leaky ReLU, ELU, GELU) стремятся устранить насыщение вовсе.

На практике выбор функции активации зависит от роли слоя:

- **скрытые слои** — почти всегда ReLU или один из её современных вариантов, благодаря скорости вычисления и отсутствию затухания на положительной части;
- **выходной слой при бинарной классификации** — сигмоида, поскольку её выход естественно интерпретируется как вероятность принадлежности к одному из двух классов;
- **выходной слой при многоклассовой классификации** — softmax, дающий распределение вероятностей по нескольким классам одновременно;
- **выходной слой при регрессии** (предсказании непрерывного числа, а не класса) — активация часто вообще не применяется (то есть используется линейный выход), поскольку предсказываемое значение не обязано лежать в ограниченном диапазоне.

## Часть 11. Реализация на Python

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

def sigmoid_derivative(z):
    s = sigmoid(z)
    return s * (1 - s)

def tanh(z):
    return math.tanh(z)

def tanh_derivative(z):
    return 1 - math.tanh(z) ** 2

def relu(z):
    return max(0, z)

def relu_derivative(z):
    return 1 if z > 0 else 0

def leaky_relu(z, alpha=0.01):
    return z if z > 0 else alpha * z

def leaky_relu_derivative(z, alpha=0.01):
    return 1 if z > 0 else alpha
```

Эти функции — те же самые "кирпичики", которые в дальнейшем будут вызываться внутри каждого нейрона многослойной сети, независимо от того, сколько слоёв и нейронов в ней содержится.

## Часть 12. Итоги

1. Функция активации обязана быть дифференцируемой — иначе градиентные методы обучения не могут через неё передать сигнал об ошибке.
2. Сигмоида и tanh — гладкие, ограниченные функции, но обе подвержены насыщению и затуханию градиента на краях; tanh страдает от этого меньше за счёт центрирования вокруг нуля.
3. ReLU устраняет затухание на положительной части за счёт постоянной производной и высокой скорости вычисления, но порождает собственную проблему — необратимое "отключение" нейронов.
4. Более современные функции (Leaky ReLU, ELU, GELU, Swish) — попытки сохранить достоинства ReLU, устранив её недостатки; softmax занимает отдельное место как функция для выходного слоя многоклассовой классификации.
5. Нелинейность активации — не техническая деталь, а необходимое условие выразительной силы сети: без неё любое число слоёв эквивалентно одному линейному преобразованию, что напрямую связано с теоремой об универсальной аппроксимации.
6. Выбор конкретной функции активации на практике определяется ролью слоя (скрытый или выходной) и типом решаемой задачи (классификация или регрессия).
